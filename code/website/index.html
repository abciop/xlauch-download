FAQ

常见问题

支持哪些操作系统？+

目前支持 Windows 10 / 11（64 位）。界面基于系统自带的 WebView2 渲染，一般无需额外安装运行时；若系统缺失 WebView2，程序会自动回退到默认浏览器打开界面，功能完全一致。

是免费软件吗？有广告或捆绑吗？+

完全免费，无广告、无弹窗、无捆绑、不收集任何用户数据。程序仅监听本机回环地址（127.0.0.1），所有网络请求只用于下载任务本身。

下载的视频保存在哪里？可以改吗？+

默认保存到 d:\xdm（首次下载时自动创建），可在「设置 → 下载目录」中修改，也支持为单个任务临时指定目录。底部状态栏会实时显示当前保存位置。

关闭窗口后下载会中断吗？+

不会。默认行为是关闭/最小化时收进系统托盘，后台继续下载；也可以在「设置 → 关闭方式」中改为「直接退出」。托盘右键可随时退出程序。

抖音视频解析失败怎么办？+

公开作品无需登录即可直接解析；私密或作者设置了权限的作品属于平台限制，程序会返回明确提示。若个别视频解析超时，重试一次即可（首次解析需建立会话，稍慢）。

会员视频 / 登录后才能看的视频怎么下载？+

在浏览器里登录站点后，通过浏览器扩展一键「导出登录 Cookie」，XDM 下载该站点时自动携带登录态；也可以在设置中导入 cookies.txt 文件，或让 XDM 直接读取本机浏览器 Cookie（Chrome / Edge / Firefox）。三种来源按「扩展推送 > cookies.txt > 读取浏览器」自动择优。

浏览器扩展怎么安装？具体能做什么？+

下载扩展 zip 包解压后，在 Chrome / Edge 的「扩展程序」页打开开发者模式，选择「加载已解压的扩展程序」即可。功能：自动嗅探网页中的视频/音频资源（显示文件名与大小，点击即下载）、右键菜单把链接推送给 XDM、一键导出当前站点的登录 Cookie（含 httpOnly）。详细图文见上方「浏览器扩展」专区。

支持代理吗？+

支持。在「设置 → 代理服务器」中填入 http 或 socks5 代理地址，用于站点视频解析等场景。
