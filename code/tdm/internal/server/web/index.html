浏览器扩展插件

安装（约 30 秒）
1
解压扩展到本机
尚未解压 — 点击右侧按钮开始
2
打开浏览器扩展管理页，开启右上角「开发者模式」开关
3
加载扩展
点「加载已解压的扩展程序」，选择第 1 步解压出的目录（可先点上方「打开目录」确认位置）
受浏览器安全限制，任何程序都无法静默安装扩展；XDM 已把流程压缩到最短。安装一次后长期有效，XDM 升级无需重装。
功能与使用说明
🎯 资源嗅探 — 播放视频后点扩展图标，本页视频/音频全部列出（显示文件名与大小），点击即添加到 XDM
✨ 悬停下载 — 鼠标在视频 / 大图 / 下载链接上停留约 0.4 秒，右上角弹出「下载」浮条，点一下即添加；浮条上的 ✕ 可本次忽略该资源
🖱 右键推送 — 网页链接 / 图片 / 视频右键 →「使用 XDM 下载…」直接创建任务
🍪 导出登录 Cookie — 在抖音 / B站 / YouTube 等已登录页面一键导出，XDM 下载该站点自动携带登录态（含 httpOnly）
🔌 端口 — 默认连接 127.0.0.1:50710；修改过 XDM 端口时在扩展弹窗「连接设置」里同步
